; Uncompressed (raw, unencoded) graphics blocks -- unlike gfx_out/, these are
; NOT LZ-Toshio compressed, so there's no header to auto-detect them from;
; each entry here was found and hand-verified individually (see project
; history/commit messages for how). Format: 0xADDRESS,lengthBytes,columns
;
; These blocks are NOT known to be referenced by any pointer table or direct
; code address we've found (unlike gfx_out/'s compressed blocks), so
; RawGraphicsInserter can only write changes IN PLACE at the same fixed
; length -- there is no relocation fallback for these. Growing the tile
; count isn't possible; recoloring/redrawing within the existing tile count
; is.
;

; confirmed yet (a nearby palette bank at 0x111280 was found and every slot
; in it renders the logo "legibly" when tried, which just means the shapes
; are high-contrast enough to read under almost any palette -- not a real
; confirmation. Using default grayscale until an actual verified match is
; found).
